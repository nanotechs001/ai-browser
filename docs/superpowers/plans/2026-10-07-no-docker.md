# Without Docker Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The sandboxed browser, website QA and skill scripts work without Docker. Settings → Sandbox picks Docker
(strongest), Local (no Docker) or Auto (Docker when it is ready, Local otherwise). Local is a separate headless
browser on this computer with an empty profile of its own, that never opens this computer's own addresses, and skill
scripts run through the agent's own commands. Docker keeps working exactly as today.

**Architecture:**
- **`src/ai_browser/sandboxmode.py` (new):** which sandbox is in use. `resolve(home)` reads `AIB_SANDBOX`, then
  Settings → Sandbox; Auto asks Docker whether it is ready (at most every 30 s). `describe(home)` gives the one line AI
  Home, Settings and `doctor` show.
- **`src/ai_browser/localbox.py` (new):** `LocalSandboxes`, the same calls as `sandbox.Sandboxes` (start, ws_url, stop,
  is_running) for a separate browser per profile under `~/.ai-browser/sandboxes/<profile>/profile`, plus `running()`.
- **`src/ai_browser/netguard.py` (new):** this computer's own addresses and its network's: judged as written, and a
  name looked up. `PATTERNS` are the requests Chrome pauses for a look (CDP `Fetch`).
- **`workfs.WorkDir(virtual=False)`:** real paths, no `/work`.
- **`browser.Browser(mode="local")`:** Docker's sandbox behaviour with real paths, plus the guard on every request.
- **`engine.Engine`:** `_backend()` decides once per session; `_boxes()` gives Docker's or Local's sandboxes; `shell`
  answers without running anything on Local; `load_skill` gives the real folder.
- **The app:** the bridge disallows `mcp__ai-browser__shell` on Local and passes `AIB_SANDBOX` to each agent's
  ai-browser server; the server looks at the sandbox in a thread and sends it with the settings; Settings → Sandbox
  (`sandboxsettings.js`) and AI Home's line.
- **The command line:** `doctor` checks the sandbox in use; `stop` and `stop --all` find local browsers.

**Tech Stack:**
- Python 3.12, asyncio; `ipaddress`, `socket` (through the loop's `getaddrinfo`), `subprocess`, `websockets.sync`;
- Chrome DevTools Protocol: `Fetch.enable` at the browser level, `Fetch.continueRequest`, `Fetch.failRequest`;
- the installed Google Chrome or Brave (never downloaded), started headless with Chromium's own sandbox on;
- plain ES modules for the pages, under the pages' CSP; pytest with the fake `claude` and throwaway headless Chromes.

## Plan decisions

The user's standing word for this work: decide with the recommended option, and say each one. Where the spec leaves
a choice, or meets the code, this plan rules. Each ruling says why, and what it costs if it is wrong.

1. **Auto means Docker is *ready*: running, with its sandbox image built.**
   - *Spec says:* "Docker when it is installed and running, Local otherwise".
   - *Why:* Docker running without the image can't start a sandbox, and Local can. `Sandboxes.check()` already asks
     both, with its own one-line reasons.
   - *If wrong:* someone with Docker running but no image gets Local, and the line says "(Auto: Docker isn't ready)".
     After `ai-browser build`, Auto picks Docker within 30 seconds.
2. **A session decides its sandbox once; an agent at each start of its Claude Code.**
   - The engine's `_backend()` asks `sandboxmode.resolve` at the first call that needs it and keeps the answer: a
     session never switches sandboxes quietly (the same rule as browsers).
   - The bridge asks at each `_start()` and passes the answer to the agent's ai-browser server as `AIB_SANDBOX`, so the
     agent's Claude Code and its tools agree.
   - *If wrong:* a change in Settings reaches a working agent only when its Claude Code starts again (New chat,
     another account, a restart). Settings → Sandbox says so: "A change applies to agents and sessions that start
     after it."
3. **`AIB_SANDBOX=docker|local` wins over Settings, for one process.** It is how the app tells each agent's server, it
   lets a Claude Code session pin one, and the test suite pins `docker` by default (`tests/conftest.py`), so no
   existing test asks Docker anything. *If wrong:* a variable left in the user's shell overrides Settings; the line
   then says "(set by AIB_SANDBOX)".
4. **The guard against this computer's addresses sits in the browser, not only at `open`, `act goto` and `qa`.**
   - *Spec says:* the sandbox browser "refuses loopback, private, link-local and `.local` addresses (`open`, `act
     goto`, `qa`)".
   - *Why more:* a public page's redirect, link, picture, frame or pop-up would otherwise reach the user's own
     services: AI Browser's app on 8792, a dev server, the router. Docker's loopback was the container's own.
   - *How:* `Fetch.enable` on the browser's connection (every tab, pop-ups included; checked by hand on Chrome 154:
     redirects, pictures, meta refreshes, fetches and clicks all pause). Every navigation pauses, and its name is
     looked up; any other request pauses only when its address may be private as written. QA's link checks skip such
     addresses before asking.
   - *If wrong:* each navigation in the local sandbox waits for one name lookup (at most 3 s; the system caches
     them). Not covered: a name that resolves public at the look and private at the load (DNS rebinding), and a
     picture or script by a name that points here (only its written address is judged).
5. **Which addresses:** loopback, private (RFC 1918, IPv6 ULA), link-local, unspecified and reserved; shared
   100.64.0.0/10 (carrier NAT and tailnets such as Tailscale: "its network"); IPv4 inside IPv6 (mapped, 6to4); and the
   names `localhost`, `*.localhost` and `*.local`. *If wrong:* a public service on 100.64.0.0/10 (rare) is refused.
6. **The refusal's words.** The spec asks for "the same words Docker's sandbox gives ("QA a site on this computer in
   your own browser")", but Docker's sandbox has no words for it today: its connection simply fails. So the plan
   writes them, around the spec's sentence: "`<host>` is on this computer or its network, and the sandbox never opens
   those. QA a site on this computer in your own browser (ask the user first)". "Ask the user first", because an app
   agent can't call `sandbox_start` and a session must not switch browsers by itself.
7. **The program:** Google Chrome (or `AIB_CHROME_BINARY`) first, else Brave, as `chrome.chrome_binary()` and
   `brave_binary()` find them. *If wrong:* nothing much; Chrome is what the tests and QA's timings use.
8. **Docker's Chromium flags, minus `--no-sandbox`,** plus `--use-mock-keychain` on a Mac, so the user's Keychain is
   never asked. *If wrong:* the sandbox profile's cookies are sealed with a fixed key; programs running as the user
   could read the profile anyway (said in Settings and the README).
9. **The browser outlives the session that started it** (a session and process group of its own), so it is shared
   like the container, and stops on `sandbox_stop`, `ai-browser stop`, or, for a throwaway, when its session ends.
   *If wrong:* a named profile's browser keeps running until stopped, as Docker's container did. On Windows, one
   started under the app ends with the app (the app's job holds its children).
10. **Who counts as a profile's browser.** Its record's pid, or its `SingletonLock`'s, only when that process's
    command line names the profile (`ps`, macOS and Linux) or this process started it. On Windows: the record's pid,
    only while the profile's DevTools port answers. A process is ended only when it is the profile's browser, and on
    Windows only one this process started. *Spec:* "stale lock files are cleared only when its process is gone".
    *If wrong:* on Windows, a hung sandbox browser that another process started isn't ended by `stop`; the user ends
    it in Task Manager. Never: ending an unrelated program that took a dead browser's pid.
11. **`shell` stays a tool of the MCP server.** App agents on Local get it in `--disallowedTools`: "isn't offered". A
    Claude Code session's call answers "… Run it with your own Bash: `<command>`" and runs nothing, as the spec says.
    *Why:* a server's tool list is fixed when Claude Code starts it, before the session knows its sandbox. *If
    wrong:* a session still sees a `shell` tool that only answers.
12. **The work folder of the user's own browser follows the sandbox too:** `/work/<task>` with Docker (its shell sees
    that), the real path on Local (no shell sees `/work`). *If wrong:* a session in the user's Brave may ask Docker
    once (Auto), in a thread, before its first page.
13. **Uploads on Local are copies,** as in the user's own browser: the browser reads a copy the agent's commands
    can't swap after the check.
14. **`file:` pages on Local:** only under the sandbox's work folder (`~/.ai-browser/sandboxes/<profile>/work`, as
    `/work` is in Docker), compared after resolving links and `..`. *If wrong:* a link swapped in between the check
    and the load (only the agent's own commands write there, each asked first).
15. **`doctor` on Local** opens its page from the work folder (a page served on this computer is refused there), and
    checks the refusal itself. **`bench` stays Docker's.** *If wrong:* no local speed numbers.
16. **`stop` and `stop --all`** stop the local browsers first (no Docker needed); Docker being down is an error only
    while Docker is the sandbox in use.
17. **The app looks at the sandbox in a thread:** at start, when a page connects (Docker may have started since), and
    when the user picks one; one look at a time, and a look for an older choice is dropped. AI Home's line sits above
    New task; Settings → Sandbox has the three choices, the line and what Local gives up.
18. **No new message type:** `settings_set` (already app-only in `MESSAGE_RULES`) takes the key `sandbox`.
19. **Profile names** follow Docker's rules (`sandbox.PROFILE_RE`; `chrome` and `app` reserved), and a local
    profile's record (`browser.json`, 0600) sits beside its work folder. It holds the pid, the program and whether
    the profile is a throwaway; the port is read from the profile's own `DevToolsActivePort` each time (the spec's
    "pid and port record": the browser picks a new port at each start and writes it there itself).
20. **Unchanged:** Docker's code paths, the image and `build`; the live view (it streams any CDP browser); the Brain;
    "No web" (it already blocks the shell); the spec's Out of scope (another OS user, a pipe instead of a port, Linux
    as a target).
21. **Downloads never land in the user's Downloads folder.** CDP's download choice ends with the session that set it
    (checked by hand on Chrome 154: a download after that session left went to the browser's default, which for a
    new profile is the user's own Downloads). So each start writes the profile's own preference first: downloads go to
    `~/.ai-browser/sandboxes/<profile>/downloads` unless a session says `<task>/downloads`. *If wrong:* nothing; Brave
    reads the same preference.

- [ ] **Step 1: Write the failing tests**

The new key shows in every settings dictionary the tests compare whole, so those expectations gain

Create `tests/test_sandboxmode.py`:

```python
"""Which sandbox AI Browser uses (sandboxmode.py, the no-Docker spec): Settings → Sandbox's Auto, Docker or Local,
AIB_SANDBOX for one process, and Docker's readiness, looked at no more than every LOOK_AGAIN seconds. No test here
reaches Docker: its look (Sandboxes.check) is replaced."""

import pytest


@pytest.fixture
def docker(monkeypatch):
    """Docker's look, replaced: {"ready": bool, "looks": count}. The cache starts empty."""
    from ai_browser import sandboxmode
    from ai_browser.sandbox import DockerError, Sandboxes

    state = {"ready": True, "looks": 0}

    def check(self):
        state["looks"] += 1
        if not state["ready"]:
            raise DockerError("Docker isn't running. Start Docker Desktop, then retry.")

    monkeypatch.setattr(Sandboxes, "check", check)
    monkeypatch.setattr(sandboxmode, "_looked", {})
    monkeypatch.delenv("AIB_SANDBOX", raising=False)
    return state


def test_the_choice_is_auto_docker_or_local(tmp_path):
    from ai_browser.settings import Settings

    settings = Settings(tmp_path, system="darwin")
    assert settings.get()["sandbox"] == "auto"  # the default: Docker when it is ready, Local otherwise
    for value in ("podman", "", None, True, "Local"):
        with pytest.raises(ValueError, match="Auto, Docker or Local"):
            settings.set("sandbox", value)
    assert settings.set("sandbox", "local")["sandbox"] == "local"
    assert settings.set("sandbox", "docker")["sandbox"] == "docker"


def test_auto_picks_docker_when_it_is_ready_and_local_otherwise(tmp_path, docker):
    from ai_browser import sandboxmode

    assert sandboxmode.resolve(tmp_path) == "docker"
    assert sandboxmode.describe(tmp_path) == {"choice": "auto", "using": "docker",
                                              "line": "Sandbox: Docker (Auto: Docker is ready)"}
    docker["ready"] = False
    sandboxmode._looked.clear()  # past LOOK_AGAIN
    assert sandboxmode.resolve(tmp_path) == "local"
    assert sandboxmode.describe(tmp_path) == {"choice": "auto", "using": "local",
                                              "line": "Sandbox: Local, without Docker (Auto: Docker isn't ready)"}


def test_docker_is_asked_at_most_every_look_again_seconds(tmp_path, docker, monkeypatch):
    from ai_browser import sandboxmode

    now = [1000.0]
    monkeypatch.setattr(sandboxmode, "clock", lambda: now[0])
    for _ in range(5):
        sandboxmode.resolve(tmp_path)
    assert docker["looks"] == 1
    now[0] += sandboxmode.LOOK_AGAIN + 1
    sandboxmode.resolve(tmp_path)
    assert docker["looks"] == 2


def test_the_users_choice_and_aib_sandbox_need_no_look_at_docker(tmp_path, docker, monkeypatch):
    from ai_browser import sandboxmode
    from ai_browser.settings import Settings
```

```python
def docker_ready(image: str = IMAGE) -> tuple[bool, str]:
    """(True, "") when Docker runs and the sandbox image is built; else (False, its one-line reason)."""
    with _lock:
        seen = _looked.get(image)
        if seen is not None and clock() - seen[0] < LOOK_AGAIN:

        ready, why = True, ""

    with _lock:

    return ready, why

    pinned = forced(env)

    choice = Settings(home).get()["sandbox"]
```

```python
services and its network's, which Docker's browser couldn't: its loopback was the container's own. So it never opens
them: loopback, private, link-local, shared (100.64.0.0/10, tailnets) and unspecified addresses, and the names
localhost, *.localhost and *.local.
- An address is judged as written (Chrome writes every address in one form first, so 2130706433 and 0x7f.1 reach it
  as 127.0.0.1).
- A name an agent opens, and every navigation's, is also looked up: a public name that points here (localtest.me) is
  refused too.
The browser applies it to every request it makes (browser.py: CDP Fetch with PATTERNS), and open, act goto and qa
say so before anything loads."""

from __future__ import annotations

import asyncio
import ipaddress
from urllib.parse import urlsplit

REFUSED = ("{host} is on this computer or its network, and the sandbox never opens those. QA a site on this computer "
           "in your own browser (ask the user first)")
SHARED = ipaddress.ip_network("100.64.0.0/10")  # carrier-grade NAT, and tailnets (Tailscale)
LOOKUP_WAIT = 3.0  # seconds a name's lookup may take; past it, the browser decides (it looks the name up itself)
# The requests Chrome pauses for a look (CDP Fetch patterns: * and ? only). Every navigation (Document) pauses, so its
# name is looked up; any other request pauses only when its address may be private as written. The look decides.
PATTERNS = [{"urlPattern": "*", "resourceType": "Document", "requestStage": "Request"},
            *({"urlPattern": pattern, "requestStage": "Request"} for pattern in (
                "*://localhost*", "*://*.local*", "*://0.*", "*://10.*", "*://127.*", "*://100.*", "*://169.254.*",
                "*://172.1?.*", "*://172.2?.*", "*://172.3?.*", "*://192.168.*", "*://[*"))]


def exempt(url: str) -> bool:
    """Never, outside the test suite. The tests serve their pages on this computer, and let only those through by
    replacing this function."""
    return False


def private_address(address: ipaddress.IPv4Address | ipaddress.IPv6Address) -> bool:
    if address.version == 6:  # an IPv4 address carried in an IPv6 one is judged as itself
        carried = address.ipv4_mapped or address.sixtofour
        if carried is not None:
            address = carried
    return (address.is_private or address.is_loopback or address.is_link_local or address.is_unspecified
            or address.is_reserved or (address.version == 4 and address in SHARED))


def private_host(host: str) -> bool:
    """Whether a host, as written, is this computer or its network."""
    name = (host or "").strip().strip("[]").rstrip(".").lower()
    if not name:
        return False
    if name == "localhost" or name.endswith((".localhost", ".local")):
        return True
    try:
        return private_address(ipaddress.ip_address(name.split("%", 1)[0]))  # fe80::1%en0: the zone isn't the address
    except ValueError:
        return False  # a name: only a lookup can say


def host_of(url: str) -> str:
    try:
        return urlsplit(str(url).strip()).hostname or ""
    except ValueError:
        return ""


def private_url(url: str) -> bool:
    """Whether an address names this computer or its network, as written (no lookup)."""
    return not exempt(url) and private_host(host_of(url))


async def refused(url: str) -> str | None:
    """The refusal for an address the sandbox's browser never opens, or None: as written, then its name looked up."""
    if exempt(url):
        return None
    host = host_of(url)
    if not host:
        return None  # data:, about:blank, a file in the work folder: no network
    if private_host(host):
        return REFUSED.format(host=host)
    try:
        ipaddress.ip_address(host)
        return None  # a public address, as written
    except ValueError:
        pass
    try:
        found = await asyncio.wait_for(asyncio.get_running_loop().getaddrinfo(host, None), LOOKUP_WAIT)
    except (OSError, UnicodeError, TimeoutError):
        return None  # not found (the browser can't open it either), or too slow to say
    for *_, address in found:
        try:
            if private_address(ipaddress.ip_address(str(address[0]).split("%", 1)[0])):
                return REFUSED.format(host=host)
        except ValueError:
            continue
    return None
```

```python
"""The sandbox's browser without Docker (the no-Docker spec): a separate browser on this computer. AI Browser starts the
installed Google Chrome (else Brave) on a profile of its own, <home>/sandboxes/<profile>/profile (0700): none of the
user's logins, cookies or history, and never one of the user's own profile folders (chrome.launch refuses them).
- Headless, with Chromium's own sandbox on (no --no-sandbox). Logging in and bot checks use the live view, as in
  Docker.
- One browser per profile, shared by every session on it, as the container was. Its record, browser.json (its pid,
  its program, whether it is a throwaway), lets stop and `ai-browser stop --all` find it.
- Its DevTools port is on 127.0.0.1 only, named in the profile's own DevToolsActivePort, inside the 0700 folder.
- A throwaway (fresh) profile is removed when its browser stops; the work folder stays, as in Docker.
- Its downloads stay in the sandbox's folders, never the user's Downloads, even while no session is connected.
- Lock files a browser left are cleared only once its process is gone. A process counts as the profile's browser only
  when its command line names the profile (macOS, Linux), or this process started it.
It is a separate profile on this computer, not a separate machine: Settings and the README say so."""

from __future__ import annotations

import contextlib
import json
import os
import secrets
import signal
import subprocess
import sys
import time
from pathlib import Path

from . import platforms
from .chrome import ChromeError, _listening, _port_of, brave_binary, chrome_binary, launch
from .sandbox import PROFILE_RE, SandboxInfo
from .syncdir import write_atomic

READY_TIMEOUT = 20  # seconds a new browser gets to answer
ANSWER_WAIT = 5.0  # seconds a running browser gets to answer before it is said not to
STOP_WAIT = 10  # seconds a browser gets to close by itself before it is ended
RECORD = "browser.json"
LOCKS = ("SingletonLock", "SingletonSocket", "SingletonCookie", "lockfile", "DevToolsActivePort")
# As Docker's Chromium runs (docker/entrypoint.sh), minus --no-sandbox: Chromium's own sandbox stays on here
FLAGS = ("--disable-extensions", "--disable-background-timer-throttling", "--disable-renderer-backgrounding",
         "--disable-backgrounding-occluded-windows", "--disable-features=Translate,MediaRouter",
         "--disable-smooth-scrolling", "--mute-audio", "--password-store=basic")
MAC_FLAGS = ("--use-mock-keychain",)  # the user's Keychain is never asked
NO_BROWSER = ("Without Docker, the sandbox needs Google Chrome or Brave on this computer: install one, or start Docker "
              "Desktop and pick Docker in Settings → Sandbox")
_launched: dict[int, subprocess.Popen] = {}  # browsers this process started: polled, so one that ended is reaped


def sandbox_binary() -> str | None:
    """The browser the local sandbox runs: Google Chrome ($AIB_CHROME_BINARY too), else Brave. Never downloaded."""
    return chrome_binary() or brave_binary()


def _alive(pid: int) -> bool:
    process = _launched.get(pid)
    return process.poll() is None if process is not None else platforms.pid_alive(pid)


def _answers(profile: Path) -> bool:
    """Whether the profile's browser answers: its DevToolsActivePort names a port that takes a connection."""
    found = _port_of(profile)
    return found is not None and _listening(found[0])


def _keep_downloads_in(profile: Path, folder: Path) -> None:
    """Downloads land in the sandbox's own folder even while no session says where: CDP's download choice ends with the
    session that set it, and the browser's own default is the user's Downloads folder. The profile's preference,
    written before each start (the browser isn't running then), names the sandbox's folder instead."""
    path = profile / "Default" / "Preferences"
    try:
        data = json.loads(path.read_text(encoding="utf-8"))
    except (OSError, ValueError):
        data = {}
    data = data if isinstance(data, dict) else {}
    for key in ("download", "savefile"):
        data[key] = {**(data.get(key) if isinstance(data.get(key), dict) else {}), "default_directory": str(folder)}
    data["download"]["prompt_for_download"] = False
    write_atomic(path, json.dumps(data).encode("utf-8"), 0o600)


def _lock_pid(profile: Path) -> int | None:
    """The pid in Chromium's SingletonLock (a link to "host-pid"; Windows has none), or None."""
    try:
        tail = os.readlink(profile / "SingletonLock").rsplit("-", 1)[-1]
    except OSError:
        return None
    return int(tail) if tail.isdigit() else None


def _runs_profile(pid: int, profile: Path) -> bool:
    """Whether a running process is a browser on this profile: this process started it, or (macOS, Linux) its command
    line names the profile folder. Never a guess from a pid alone: pids are reused."""
    if pid in _launched:
        return _launched[pid].poll() is None
    if platforms.WINDOWS or not platforms.pid_alive(pid):
        return False
    try:
        line = subprocess.run(["ps", "-ww", "-o", "command=", "-p", str(pid)], capture_output=True, text=True,
                              encoding="utf-8", errors="replace", timeout=5).stdout
    except (OSError, subprocess.SubprocessError):
        return False
    return f"--user-data-dir={profile}" in line


class LocalSandboxes:
    """sandbox.Sandboxes' calls for the engine (start, ws_url, stop, is_running), and running() for `stop --all`."""

    def __init__(self, home: Path):
        self.home = Path(home)

    def _folder(self, profile: str) -> Path:
        return self.home / "sandboxes" / profile

    def start(self, profile: str = "default", fresh: bool = False) -> SandboxInfo:
        if fresh:
            profile = "fresh-" + secrets.token_hex(3)
        elif profile in ("chrome", "app"):  # their folders and sessions belong to your-own-Chrome mode and AI Browser
            raise ValueError(f"profile {profile!r} is reserved (your own Chrome and AI Browser use it): pick another "
                             "profile name")
        elif not PROFILE_RE.match(profile):
            raise ValueError(f"profile {profile!r}: use lowercase letters, digits and dashes (max 31)")
        folder = self._folder(profile)
        work_host = folder / "work"
        work_host.mkdir(parents=True, exist_ok=True)
        with self._one_start(folder):
            port, created = self._running_port(folder), False
            if port is None:
                port, created = self._launch(folder, fresh), True
        return SandboxInfo(f"aib-{profile}", profile, f"http://127.0.0.1:{port}", work_host, fresh, created,
                           local=True)

    @contextlib.contextmanager
    def _one_start(self, folder: Path):
        """One start of a profile's browser at a time, across processes: two sessions starting at once share one."""
        deadline = time.monotonic() + READY_TIMEOUT + 5
        while (lock := platforms.lock_file(folder / "start.lock")) is None:
            if time.monotonic() > deadline:
                raise ChromeError(f"another start of the sandbox browser for profile {folder.name} didn't finish: "
                                  "try again")
            time.sleep(0.1)
        try:
            yield
        finally:
            lock.close()

    def _record(self, folder: Path) -> dict:
        try:
            data = json.loads((folder / RECORD).read_text(encoding="utf-8"))
        except (OSError, ValueError):
            return {}
        return data if isinstance(data, dict) else {}

    def _owner(self, folder: Path) -> int | None:
        """The pid of the browser that holds the profile (its record's, else its lock's), or None when none runs."""
        profile = folder / "profile"
        recorded = self._record(folder).get("pid")
        if isinstance(recorded, int) and recorded > 0:
            if _runs_profile(recorded, profile):
                return recorded
            if platforms.WINDOWS and platforms.pid_alive(recorded) and _answers(profile):  # no ps: its port says
                return recorded
        locked = _lock_pid(profile)
        return locked if locked is not None and _runs_profile(locked, profile) else None

    def _clear(self, folder: Path) -> None:
        """No browser holds the profile: the lock files, the port file and the record it left are stale."""
        profile = folder / "profile"
        try:
            for name in LOCKS:
                platforms.unlink(profile / name, missing_ok=True)  # SingletonLock links to nothing: never exists()
            platforms.unlink(folder / RECORD, missing_ok=True)
        except PermissionError:  # Windows: a browser still holds its lockfile
            raise ChromeError(f"another browser holds the sandbox profile {folder.name}: run "
                              f"`{platforms.command('stop ' + folder.name)}`, then try again") from None

    def _running_port(self, folder: Path) -> int | None:
        """The DevTools port of the profile's browser, when one runs and answers; None when none runs (what it left
        is cleared then). One that runs but doesn't answer is never touched: ChromeError."""
        pid = self._owner(folder)
        if pid is None:
            self._clear(folder)
            return None
        deadline = time.monotonic() + ANSWER_WAIT
        while True:
            found = _port_of(folder / "profile")
            if found is not None and _listening(found[0]):
                return found[0]
            if not _alive(pid):
                self._clear(folder)
                return None
            if time.monotonic() > deadline:
                raise ChromeError(f"the sandbox browser for profile {folder.name} runs but doesn't answer: run "
                                  f"`{platforms.command('stop ' + folder.name)}`, then try again")
            time.sleep(0.1)

    def _launch(self, folder: Path, fresh: bool) -> int:
        binary = sandbox_binary()
        if binary is None:
            raise ChromeError(NO_BROWSER)
        profile = folder / "profile"
        profile.mkdir(parents=True, exist_ok=True)
```

  under the work folder (after links and `..`);
- `_reach(url)` looks a name up before `open`, a new tab and `act goto` load anything;

```javascript
export function sandboxLine(state) { // the app's one line: "Sandbox: Docker", "Sandbox: Local, without Docker", …
  return state && typeof state.line === "string" ? state.line : "";

export function mountSandboxSettings(parts, send) {
  // parts: {choices, state}
  let chosen = "auto";

  function render() {
    if (!parts.choices.dataset.built) { // the three choices, once
      for (const choice of SANDBOX_CHOICES) {
        const label = document.createElement("label");
        const input = document.createElement("input");
        input.type = "radio";
        input.name = "sandbox";
        input.value = choice.value;
        input.addEventListener("change", () => {
          if (input.checked) send({ type: "settings_set", key: "sandbox", value: choice.value, request: "sandbox" });
```
