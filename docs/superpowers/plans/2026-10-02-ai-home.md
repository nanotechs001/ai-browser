# AI Home Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** AI Browser becomes a normal Chrome with **AI Home**, a dashboard of every tab, every agent and all of
Claude's skills. Up to three Claude agents work at once, each in its own tabs, which sit in Chrome tab groups.

**Architecture:**
- **Launcher:** starts headed AI Browser without the DevTools pipe, so it is a normal Chrome. The extension is
  installed once by the user; the app computes its ID from the folder path and checks the profile's Preferences.
- **The app process** runs:
  - an `AgentManager`: one `ClaudeBridge` (one `claude -p` process) per agent, three working at once, the rest in a
    first-come-first-served line;
  - a `TabWatch`: its own CDP connection for the tab list, Watch, closing agents' tabs and thumbnails;
  - the app server: one token-guarded WebSocket for AI Home, the panel and the extension worker, plus
    `POST /agent-events`, where each agent's engine reports the tabs it uses.
- **The extension** provides:
  - AI Home (`home.html`): the new tab page and a pinned tab;
  - the chat panel, which follows the current tab's agent;
  - a module worker: tab groups, the badge and the `ai` address-bar keyword.

**Tech Stack:** Python 3.12, asyncio, Starlette and uvicorn, httpx, websockets, the existing CDP client; an MV3
extension in plain HTML, CSS and JS (ES modules); Claude Code 2.1.263 (`claude -p`, stream-json with control requests);
pytest with throwaway headless Chrome and the fake `claude`.

**Spec:** `docs/superpowers/specs/2026-10-02-ai-home-design.md`

## Global Constraints

- **No API keys:** the bridge never passes `--bare`. It strips `ANTHROPIC_API_KEY` and `ANTHROPIC_AUTH_TOKEN` from
  Claude Code's environment.
- **Claude's tools:** always `--tools "" --strict-mcp-config --allowedTools "mcp__ai-browser__*" --disallowedTools
  mcp__ai-browser__sandbox_start --permission-mode dontAsk --setting-sources local`.
- **Headed AI Browser is a normal Chrome.** It never starts with `--remote-debugging-pipe`,
  `--enable-unsafe-extension-debugging` or `--enable-automation`. Only headless launches (tests) install over the pipe.
- **Server:**
  - binds 127.0.0.1 only;
  - compares tokens in constant time;
  - accepts UI sockets only from our extension's origin with the extension token;
  - accepts `POST /agent-events` only with the agent token, which is a different token.
- **Text is text:** text from Claude, pages, skills and tab titles is rendered with `textContent` only. Thumbnails are
  shown only as `data:image/jpeg;base64,` images made by the app.
- **Tabs:**
  - an agent never closes a tab it did not open;
  - adopted (user) tabs are never closed, not by `tabs close`, a session ending or a crash;
  - the app closes an agent's own tabs only when the user closes the agent.
- **URLs:** in app mode, `open` and `goto` refuse `chrome-extension://`, `file://` and `chrome://`.
- **Agent limit:** three working agents by default (`AIB_APP_MAX_AGENTS`). More wait in line, first come first served.
- **Page data:** title at most 150 characters; URL scheme, host and path only, at most 300 characters; labelled as
  page data (existing `page_line`).
- **Files that hold tokens** (`config.json`, every agent's `mcp.json`) are written with mode 0600.
- **No git** in this repo. Wherever a step says "Ledger", append a line to
  `.superpowers/sdd/2026-10-02-ai-home/progress.md`.

## Review Focus

1. **The user closes an agent's working tab mid-task:** the agent carries on in a new background tab and AI Home shows
   the new tab. Test: Task 2.
2. **The user drags an agent's tab out of its group:** the worker groups each tab once and never regroups a tab the user
   moved. Test: Task 7.
3. **The app restarts while AI Home or the panel stays open** (new port, new token): the page reads `config.json` again
   before every connection attempt and reconnects. Test: Task 7.
4. **An agent with thousands of events** (a long QA run): the snapshot carries no events, and an agent's history is
   capped at 5000, newest kept. Test: Task 6.
5. **Start double-clicked, or two AI Home tabs:** one request makes exactly one agent, and the Start button stays off
   until the server answers. Test: Task 7.

- **`@dataclass Agent`:**
  - fields: `id`, `name`, `color`, `model`;
  - `state` is one of `"working"`, `"waiting"`, `"your_turn"`, `"stopped"`, `"failed"`;
  - `status: str` (tool and summary, or the failure reason), `last_action: str` (for example `click e14 · 38 ms`);
  - `tabs: list[str]` (opened by the agent), `adopted: list[str]` (the user's), `working_tab: str | None`;
  - `loaded_skills: list[str]`, `seconds: float`, `cost: float`, `created: float`;
  - `events: deque` (maxlen `KEEP_EVENTS`) and `pending: list[str]`;
  - `public() -> dict`: every field except `events`, `pending` and the bridge.
- **`AgentManager(home, claude=None, max_working=3, env=None, close_tabs=None, on_action=None)`:**
  - `env` holds the extra MCP env for every agent. The `AIB_APP_*` values are set by run_app after launch.
  - `close_tabs`: `async (targets: list[str]) -> None`.
  - `on_action`: `(agent: Agent) -> None`, called after each `tool_result`; the server takes thumbnails there.
  - **Commands:**
    - `async create(text, skills=(), model="sonnet", adopt=None, tab=None) -> Agent`: the name is the task's first
      words, up to 40 characters; ids are `a1`, `a2`, …;
    - `async send(agent_id, text, tab=None)`: when the agent is working, the text is queued and an `{"type": "queued",
      "text"}` agent_event is broadcast. It is delivered when its turn ends, in the same slot;
    - `async stop(agent_id)`: a working agent gets `bridge.stop()` and its pending messages are dropped; a waiting one
      leaves the line and becomes `"stopped"`;
    - `async close(agent_id)`:
      1. stop it;
      2. wait up to 10 s for its turn to end;
      3. `bridge.close()`;
      4. `await close_tabs(agent.tabs)` (adopted tabs never);
      5. drop the agent and broadcast `{"type": "agent_closed", "id"}`;
    - `set_model(agent_id, model)`;
    - `tab_event(agent_id, kind, target, adopted=False)`;
    - `async close_all()`.
  - **Views:**
    - `snapshot() -> {"agents": [public…]}`, newest first;
    - `events_of(agent_id) -> list[dict]`;
    - `subscribe() -> asyncio.Queue` and `unsubscribe(queue)`.
  - **Broadcasts:**
    - `{"type": "agent", "agent": public}` on every change;
    - `{"type": "agent_event", "id", "event"}` for every bridge event, which is also kept in `agent.events`.
  - **Each agent's bridge:**
    `ClaudeBridge(home, model, claude, env={**env, "AIB_APP_AGENT": id, **({"AIB_APP_ADOPT": adopt} if adopt else {})}, agent_id=id)`.
  - **Bridge events update the agent:**
    - `tool` → `status = f"{name} {summary}"`;
    - `tool_result` → `last_action = f"{name} {summary} · {ms} ms"` (summary looked up by id), then `on_action`;
    - `done` → state `"your_turn"`, or `"stopped"` when `stopped`; add `seconds` and `cost`;
    - `error` → state `"failed"`, `status = text`;
    - `load_skill` tools → `loaded_skills = sorted(bridge.loaded_skills)`.
