# Frames From Another Site (Read and Act Inside Iframes) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** AI Browser's agents read and act inside frames from another site (GoHighLevel's page builder is one) as they
do on the page itself: numbered rows tagged with their frame, clicks, typing, native `<select>` menus and scrolling.
Bot-check frames are never read or touched. Through the app's relay, a tab's frames reach only the agent whose tab it
is.

**Architecture:**
- **Attaching (`browser.py`, Task 3):** each tab's session turns on `Target.setAutoAttach` (frames only, flattened,
  never paused at their start). Chrome then gives each frame that runs in a process of its own a session; the Browser
  follows it as a `Frame` (`Tab.frames`). Its address comes a moment after it is attached (`Target.targetInfoChanged`):
  a bot check's (`checks.CHECK_FRAME`, the same list as `reader.js`'s) is let go of at once, before anything is sent to
  it; any other is followed (`Page.enable`, so a download it starts is caught as the page's, and its own frames are
  attached, 5 deep).
- **Reading (`state()` → `_read_frames`, Task 4):** the page's reader first, as today, then each frame's own reader,
  parents before children: in AI Browser's isolated world, on the frame's own session, or, for another origin on the
  same site (it runs in its parent's process), on its parent's session with its frame id. The `<iframe>` element is
  found with `DOM.getFrameOwner` and handed to the parent's reader (`frameAt`): its content box and the scale a CSS
  transform or zoom gives it place the frame on the page. The frame's reader gets that placement (`opts.at`), so "in
  view" means in the page's view. All readers number their rows from one count (`opts.next`); `Tab.inside` remembers
  each frame row's frame. 20 frames, 2 seconds, 5 deep.
- **Acting (Task 5):** `_where(element)` names the row's frame. `target()` runs in that frame's reader with the frame's
  placement read again now, and returns a position on the page, where the click (real input, as today) lands. Type,
  select, check, upload and `scroll eN` run in the frame. A row whose frame became a bot check's is refused.
- **The relay (`app/cdprelay.py`, Task 2, security-sensitive):** `Target.setAutoAttach` on a tab's session (always
  frames only, never paused) and letting go of a frame on the session it was attached under. Each frame's session
  belongs to the client whose tab it is in, with the page's own policy and address check. Take back cuts a tab's frames
  with it; anything but a frame is never handed on.
- **Rendering (`render.py`, Task 6):** the frames line names a read frame plainly (`[page-builder]`) and keeps
  `(not readable)` only for one that couldn't be read; a page drawn on a `<canvas>` gets one line saying so.

**Tech Stack:**
- Python 3.12, asyncio; the Chrome DevTools Protocol over one websocket (`cdp.CDP`), flattened sessions;
- the page reader (`reader.js`, plain JavaScript in AI Browser's isolated world);
- the app's relay (Starlette websocket, `app/cdprelay.py`);

## Plan decisions

Where the spec leaves a choice, or meets the code, this plan rules. Each ruling says why, and what it costs if it is
wrong.

1. **The relay comes before the engine (Task 2, then Task 3).**
   - *Why:* the engine's frame tests run both ways from their first task, directly and through the relay (conftest's
     `RELAYED_MODULES`), and the relay's drift guard (`test_every_method_the_engine_sends_passes_the_policy`) fails the
     moment `browser.py` sends `Target.setAutoAttach` unless the relay already passes it.
   - *If wrong:* nothing; it is only the order. The end-to-end relay test still comes after the engine (Task 7).
2. **A bot check's frame is let go of at once, by its address, before anything is sent to it.**
   - *Spec says:* "never attached, never read, never acted in".
   - *Measured (Chrome, 2026-10-09):* `Target.setAutoAttach` attaches every frame of the tab, check frames too, and a
     new frame's address is empty when it is attached; it comes a moment later in `Target.targetInfoChanged`, on the
     parent's session (and through the relay with it).
   - *So:* the engine sends a new frame nothing until its address is known. A check's frame (`CHECK_FRAME`) is then
     let go of (`Target.detachFromTarget`) and never read; one that becomes a check's later is let go of then, and a
     step on one of its old rows is refused ("is in a bot check box: the user ticks it, never you").
   - *If wrong:* a check's frame is attached, with nothing sent to it, for the moment Chrome takes to tell its address.
3. **`CHECK_FRAME` gains Arkose's two hosts** (`arkoselabs.com`, `funcaptcha.com`), in `reader.js` and in its Python
   twin in `checks.py`, kept the same text by a test.
   - *Why:* the spec names Arkose in the check list; today's list doesn't have it.
   - *If wrong:* an Arkose frame's address and size join the page's check signals, which no rule reads (`detect` and
     `box_frames` look for reCAPTCHA, hCaptcha and Cloudflare only).
4. **Letting go of a frame goes on its parent's session, and the relay passes that too.**
   - *Measured:* `Target.detachFromTarget` at the browser's level answers "No session with given id" for an
     auto-attached frame. It works only on the session the frame was attached under.
   - *So:* the relay passes `Target.detachFromTarget` on a client's session only when it names a frame attached under
     that very session, and sends `{"sessionId"}` alone.
   - *If wrong:* one more method on a tab's session, and it only ever ends a session.
5. **A frame's session gets the page's policy, `Target.setAutoAttach` included, so frames inside frames are read.**
   - *Measured:* a tab's auto-attach stops at its own frames: a frame from another site inside a frame from another
     site is attached only once the outer frame's session asks too.
   - *Spec says:* "Target.setAutoAttach allowed only on a page session" and "a child session gets the same per-session
     policy as a page". This plan reads the first as "on a tab's session, never at the browser's level" (where it would
     attach every tab of the user's), as the second says.
   - *What the relay sends:* always `{"autoAttach": <the client's, true or false>, "waitForDebuggerOnStart": false,
     "flatten": true, "filter": [{"type": "iframe"}]}`, whatever the client asked.
   - *If wrong:* refuse it on a session whose `parent` is set (one line in `_command`); a frame inside a frame from
     another site is then read directly but not through the relay.
6. **Only frames are handed on.** The relay hands an attach on only when its type is `iframe` (the filter is forced
   too). *Measured:* the builder's dedicated worker is never attached. *If wrong:* nothing; it is a second lock.
7. **A frame's downloads keep today's rule (the user's OK).**
   - *Measured:* a download started in a frame of its own process is told only on that frame's own session
     (`Page.downloadWillBegin`, once `Page.enable` is sent there); a frame's dialogs are told on the tab's session.
   - *So:* a followed frame gets `Page.enable`, and `_on_download` finds the tab from a frame's session too.
   - *If wrong:* without it, a link inside the builder could save a file to the user's Downloads folder without asking.
8. **Rows share one count; a frame's rows follow the page's.**
   - Each reader keeps its own ids per element, as today. The engine passes the tab's next free number to every reader
     (`opts.next`) and takes back the reader's (`next`), reading one after another, so ids never collide and stay put
     between reads. `Tab.inside` maps a frame's row to its `Frame`.
   - A frame's rows come after the page's, frame by frame, each in its own reading order (not interleaved with the
     page's by position).
   - *If wrong:* the order of rows; each carries its frame's label either way.
9. **Placement is the parent reader's, with the element Chrome names.**
   - `DOM.getFrameOwner` (on the session the `<iframe>` lives in) → `DOM.resolveNode` into that document's isolated
     world → `Runtime.callFunctionOn` → `window.__aib.frameAt(this)`: the content box's corner and the scale (drawn
     size over layout size). *Measured* right for `transform: scale()` and CSS `zoom`. Placements of nested frames
     compose (`on_page`).
   - Before a step, the frame is placed again. When the element had to be scrolled into view, the page may have
     scrolled too: the frame is placed again and asked once more, after the page settles (two animation frames).
     *Measured:* a click sent straight after missed, because a frame of its own process is hit where it was last drawn.
   - *If wrong:* three small CDP calls per frame per read (about a millisecond each).
10. **A frame out of view is skipped, but never called "not readable".** It shows as `[label]` (there is nothing of it
    in view to read); `find` reads it anyway. `(not readable)` means: no address yet, gone, crashed, an error, or past
    the 20-frame or 2-second limit. *If wrong:* an out-of-view frame's rows aren't counted in "below".
11. **Another origin on the same site** (it runs in its parent's process): found with `Page.getFrameTree` on its
    parent's session at each read (a `securityOrigin` other than the reading document's; `about:` frames go with their
    parent), read with its frame id. Only directly in a document a reader of its own reads: a frame inside such a frame,
    or a frame of its own process whose `<iframe>` sits in one, shows as `(not readable)`. *If wrong:* those two
    nestings stay unread; the README's Limits says so.
12. **Limits: 20 frames per observe, 2 seconds for all of them, 5 deep** (`MAX_FRAMES`, `FRAME_TIME`, `MAX_DEPTH`).
    *If wrong:* a frame slower than that shows `(not readable)` in that observe; the next observe tries again.
13. **A frame's check signals join the page's.** A check box inside a frame is marked `[bot check box: the user ticks
    it]`, and a picture challenge inside a frame stops the agent as one on the page does. *If wrong:* nothing new is
    read: the signals are each frame's own addresses and sizes of its check frames.
14. **A canvas editor gets one line.** A visible `<canvas>` over a quarter of a document's view sets `canvas`; observe
    adds "(part of this page is drawn on a canvas, which has nothing to read: take a screenshot to see it)". *If
    wrong:* a page with a big decorative canvas gets a line it doesn't need.
15. **A screenshot of one element in a frame is refused with what to do** ("take a screenshot of the page instead"):
    the reader's `rect()` measures in the frame's own coordinates. *If wrong:* nothing; whole-page shots show frames.
16. **Test pages:** served by `testpages.serve_host()` on `localhost:<port>`; the canvas from `127.0.0.1:<the same
    port>` (another site). *Measured:* headless Chrome makes it a target of its own by default (no `--site-per-process`
    needed; Task 1 checks it every run). The side frame comes from `localhost:<the second port>` (the same site,
    another origin: Chrome keeps it in the page's process).
17. **`test_chrome_mode_leaves_the_users_tabs_alone` waits for the closed tab to go** (Task 3), up to 2.5 seconds.
    - *Why:* it failed in two dry runs of this plan, each time after the frames tests in the same run. *Measured,*
      without any of this plan's changes: `Target.closeTarget` answers before the tab is gone, and the tab was still
      listed right after in 4 of 20 tries (0 of 20 with auto-attach on). The test read the list once.
    - *If wrong:* nothing: it still fails if the tab stays.

## Global Constraints

Copied from the spec. Every task's requirements include these.

- "**Bot-check frames are never read or touched.** A frame whose address matches the check list (`CHECK_FRAME`:
  reCAPTCHA, hCaptcha, Turnstile, Arkose…) is never attached, never read, never acted in; it stays `[bot check box: the
  user ticks it]`. The engine refuses an action whose element sits in such a frame." (Plan decision 2 says what
  "never attached" can mean.)
- "**Page text is data**, from any frame, as today."
- "**Only the agent's own tab's frames.** A child session belongs to its tab's owner; another client's or the user's
  other tabs' frames are never attached through the relay."
- "**The relay** (`app/cdprelay.py`) gains `Target.setAutoAttach` on a page session and routes each child session to
  the client whose page it belongs to; a child session gets the same per-session policy as a page (`Runtime`, `DOM`,
  `Input`, `Log`, the listed `Page.*` methods), and the same address checks on navigation. Nothing else is opened.
  This is security-sensitive and gets the strict review."
- "Downloads, file pickers, dialogs, permission prompts in a frame keep today's rules (the user's OK)."
- "Rows keep one number space for the page: the agent sees `[12] button "Book now" [page-builder]` as today's
  same-site frames are labelled. A row remembers its frame (its session or execution context), so `act` reaches it
  there."
- "`observe`'s frames line names a frame from another site as readable (`[page-builder]`) when it was read, and keeps
  `(not readable)` only for a frame that couldn't be (still loading, crashed, detached)."
- "Limits: at most 20 frames read per observe; a frame whose box is under 20×20 px or not in view is skipped as today;
  the reader's time budget is shared, so a page with many frames can't stall observe."
- "An editor drawn on `<canvas>` (Figma, Canva) has nothing to read: `observe` says so, and the agent keeps working
  from screenshots and positions, as today."
- Out of scope: "Reading `<canvas>` content; frames in the user's tabs the agent wasn't handed; changing GHL's own UI."

```python
"""Frames from another site (the frames spec): a fake page builder whose canvas is a frame from another site, drawn at
three quarters of its size, in a throwaway headless Chrome (never the user's Brave). The Browser reads and drives it
directly and through the app's relay (conftest's RELAYED_MODULES), as a Claude Code session and the app's agents do."""

import asyncio
from urllib.parse import urlsplit

import pytest

from ai_browser import testpages
from ai_browser.browser import Browser
from ai_browser.chrome import chrome_binary
from ai_browser.config import Config
from ai_browser.workfs import WorkDir
from conftest import browser_connection

CHROME = pytest.mark.skipif(chrome_binary() is None, reason="Google Chrome is not installed")


@pytest.fixture
async def builder(throwaway_chrome, tmp_path, route):
    """(a started Browser in chrome mode, direct or through the app's relay; the fake builder's address). The builder is
    on localhost, its canvas on 127.0.0.1 (another site), its side frame on the test pages' second port."""
    base, other, stop_pages = testpages.serve_host()
    async with browser_connection(throwaway_chrome, route, tmp_path / "relay-home") as cdp:
        browser = Browser(cdp, WorkDir(tmp_path / "work", "frames"), Config(), mode="chrome")
        await browser.start()
        try:
            yield browser, f"{base}frames/builder.html?other={urlsplit(other).port}"
        finally:
            await browser.close()
    stop_pages()


@CHROME
@pytest.mark.direct_only  # the test pages themselves, in Chrome's own target list
async def test_the_canvas_runs_in_a_process_of_its_own(builder):
    browser, page = builder
    await browser.open(page)
    frames = set()
    for _ in range(50):
        infos = (await browser.cdp.send("Target.getTargets"))["targetInfos"]
        frames = {urlsplit(info["url"]).path for info in infos if info["type"] == "iframe"}
        if len(frames) >= 2:
            break
        await asyncio.sleep(0.1)
    # The canvas and the frame inside it are each a target of their own, as GoHighLevel's builder is. The side frame
    # (the same site, another port) runs in the page's process: no target.
    assert frames == {"/frames/canvas.html", "/frames/nested.html"}
```

### Task 3: The engine follows a tab's frames, and lets a bot check's go at once

```python
    def _session_root(self, session: str | None) -> tuple[Tab | None, Frame | None]:
        """(the tab, and the frame of its own process or None for the tab's page) that `session` is the session of."""
        for tab in self.owned.values():
            if tab.session == session:
                return tab, None
            for frame in tab.frames.values():
                if frame.session == session and frame.session != frame.host:
                    return tab, frame
        return None, None

    def _on_frame_attached(self, params: dict, session: str | None) -> None:
        """Chrome attached a frame of one of our tabs, or of a frame of one (auto-attach). It is followed, and read only
        once its address is known and isn't a check's."""
        info = params.get("targetInfo") or {}
        tab, parent = self._session_root(session)
        if tab is None or info.get("type") != "iframe" or not isinstance(params.get("sessionId"), str):
            return
        depth = (parent.depth if parent else 0) + 1
        frame = Frame(str(info.get("targetId")), params["sessionId"], session, depth=depth)
        tab.frames[frame.frame] = frame
        self._frame_address(tab, frame, str(info.get("url") or ""))

    def _on_frame_changed(self, params: dict, session: str | None) -> None:
        """A frame's address came or changed (Chrome tells the session it was attached under)."""
        info = params.get("targetInfo") or {}
        for tab in list(self.owned.values()):
            frame = tab.frames.get(info.get("targetId"))
            if frame is not None and frame.session != frame.host:
                self._frame_address(tab, frame, str(info.get("url") or ""))

    def _frame_address(self, tab: Tab, frame: Frame, url: str) -> None:
        """A bot check's frame is let go of at once: nothing is ever sent to it, only the let-go on its parent's
        session. Any other frame is followed: its downloads are caught as the page's are, and its own frames are
        attached too, MAX_DEPTH deep."""
        frame.url = url
        if CHECK_FRAME.search(url):
            tab.frames.pop(frame.frame, None)
            self._later("Target.detachFromTarget", {"sessionId": frame.session}, frame.host)
        elif url and not frame.followed:
            frame.followed = True
            self._later("Page.enable", {}, frame.session)  # a download it starts is told on its own session only
            if frame.depth < MAX_DEPTH:
                self._later("Target.setAutoAttach", AUTO_ATTACH, frame.session)

    def _later(self, method: str, params: dict, session: str) -> None:
        """Send a command from an event handler, without waiting for it: a frame gone meanwhile is no error."""
        async def send() -> None:
            with contextlib.suppress(CDPError):
                await self.cdp.send(method, params, session_id=session)

        job = asyncio.ensure_future(send())
        self._cancels.add(job)  # kept until done, as a download's cancel is
        job.add_done_callback(self._cancels.discard)
```

```python
        """Read the tab's frames from another site into `page`, its page's state (the frames spec, 1). Their rows follow
        the page's, numbered on from them and labelled with their frame; their frames, text, check signals and counts
        join the page's. Parents before children, MAX_FRAMES at most, in FRAME_TIME together. A frame that can't be
        read (no address yet, gone, crashed, out of time) stays "(not readable)" in the frames line."""
        loop = asyncio.get_running_loop()
        deadline, count = loop.time() + FRAME_TIME, 0
        tab.next = max(tab.next, page.get("next") or 1)
        roots = [(tab, PAGE, page)]

            try:

        another origin in its process."""

               and frame.url and not CHECK_FRAME.search(frame.url)]

        (Page.createIsolatedWorld with their frame id). Frames of root's own origin are left to root's reader, which
        reads them as today; frames inside these are not looked for."""
        tree = (await self.cdp.send("Page.getFrameTree", session_id=root.session))["frameTree"]
        found, todo = [], [(tree, tree["frame"].get("securityOrigin"))]
        while todo:
            node, origin = todo.pop()
            for child in node.get("childFrames") or []:
```

```python
@CHROME
async def test_a_tabs_frames_reach_its_own_agent_only(relayed, throwaway_chrome, tmp_path, monkeypatch):
    """The frames spec, 3: through the relay an agent reads the frames of its own tab. Another agent gets none of them,
    the user's own tab with the same frames gives nobody anything, and only frames are attached (the builder runs a
    worker too)."""
    from urllib.parse import urlsplit

    from ai_browser.cdp import CDPError

    server, brave, base, own = relayed
    users = (await own.send("Target.createTarget", {"url": base + "frames/builder.html"}))["targetId"]
    got, dispatch = {}, CDP._dispatch

    def spy(self, message):  # every message each connection gets
        got.setdefault(id(self), []).append(json.dumps(message))
        dispatch(self, message)

    monkeypatch.setattr(CDP, "_dispatch", spy)
    engines = []
    try:
        for agent, page in (("a2", "form.html"), ("a1", "frames/builder.html")):  # a2 listens before a1's frames come
            add_agent(server.agents, agent)
            engine = agent_engine(server, throwaway_chrome, tmp_path, monkeypatch, agent)
            engines.append(engine)
            ok(await engine.open(base + page))
        two, one = engines
        for _ in range(100):
            if '"Add row"' in ok(await one.observe()):
                break
            await asyncio.sleep(0.1)
        assert "frames: [page-builder] [side] [nested]" in ok(await one.observe())  # side: no address, so blank
        frames = [frame for frame in one.browser.current.frames.values() if frame.session != frame.host]
        assert {urlsplit(frame.url).path for frame in frames} == {"/frames/canvas.html", "/frames/nested.html"}
        attached = [json.loads(message)["params"]["targetInfo"]["type"] for message in got[id(one.cdp)]
                    if json.loads(message).get("method") == "Target.attachedToTarget"]
        assert set(attached) == {"page", "iframe"}  # its tab, and its tab's frames: never the worker
        children = [session for session in brave.relay._sessions.values() if session.parent]
        assert children and all(session.page == one.browser.current.target and session.client.identity == "a1"
                                for session in children)  # none of the user's own builder tab
        assert users not in {session.page for session in brave.relay._sessions.values()}
        theirs = "".join(got.get(id(two.cdp), []))  # all a2 heard
        assert "canvas.html" not in theirs and not any(frame.session in theirs for frame in frames)
        for frame in frames:
            with pytest.raises(CDPError, match="Session with given id not found"):
                await two.cdp.send("Runtime.evaluate", {"expression": "1"}, session_id=frame.session)
    finally:
        for engine in engines:
```
