# Side Chat Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The chat beside the page moves into Brave's watcher, as Brave's side panel, one per window. There the user
talks to an agent picked in **To:**, starts a new one in their tab or in tabs of its own, hands a tab over or takes it
back with a click, and answers an agent's permission and bot-check cards. The watcher gains only `sidePanel`: no
`debugger`, no host permission and no connection to Brave of its own.

**Architecture:**
- **Server (Python):**
  - `app/tabmatch.py` (new) finds the chat's tab without `debugger`: by its address among the targets of the chat's
    own profile, then by its window (`InstanceLink.window_of`, a browser-level `Browser.getWindowForTarget` on the
    app's own relay client). Two matches, or none, are refused, never guessed;
  - `AppServer` gains chat sockets (a watcher-origin socket that said `hello` with `view: "panel"`), the messages
    `panel_place` and `tab_owners`, and the three clicks `start_here`, `hand_here` and `take_back_here`, answered by
    `hand_result` (and `hand_wait` while Brave asks). `_ready_for_hands` connects only after such a click, through the
    same shared attempt as AI Home's Connect. `_start_in` is AI Home's "start in a tab", shared with Start here;
  - wave A's two tables grow: `MESSAGE_RULES` (68 types: 32 for the watcher, 56 for the app's pages) and
    `WATCHER_RECEIVES` (27 types); `for_watcher` trims agent rows and drops each event's `page`;
  - `GroupKeeper` learns tab ids both ways (`target_of`, `known`).
- **Watcher (MV3, plain ES modules):**
  - `panel.html`, `panel.css`, `panel.js`: the chat. `sidechat.js`: its rules as pure functions. `brainpage.js`:
    `openBrain`, shared by the worker and the chat. `sidepanel.js`: the worker's panel set-up, the popup-window guard
    and `openChatFor`;
  - `manifest.json` 0.3.0 with `sidePanel`, `side_panel` and ⌘⇧Y; `worker.js` and the Brain page (a **Chat** button,
    the new promise once);
  - the shared `chat.js` and `check.js` (with `{ skip, show }`) are shipped to the watcher too.
- **Texts:** the Brain's hand-over lines and the agents' prompt point to the chat; the watcher's promise is reworded
  in five places; the Allow line names the chat's Start here and Hand over; AI Browser's old panel retires.

**Tech Stack:**
- Python 3.12: asyncio, Starlette and uvicorn, websockets;
- MV3 extension pages and a module service worker in plain JS, `chrome.sidePanel`, `chrome.tabs`, `chrome.windows`;
- pytest with a throwaway headless Google Chrome holding the watcher (the `watcher` fixture), `FakeBrave` and
  `FakePort` (tests/fake_brave.py), the fake `claude`, and CDP `Input` events for real (trusted) clicks and keys.

## Global Constraints

Copied from the spec and the user's rules. Every task's requirements include these.

**The user's safety rules:**
- **Brave's own signs stay:** "nothing answers, auto-clicks, hides or closes 'Allow remote debugging?' or the
  'controlled by automated test software' bar"; "the chat only says why Brave is asking, right after the user's click".
- **No spoofing, no way round bot checks:** "There are no user-agent or `navigator.webdriver` changes, and no way
  around bot checks." The check card offers **Show me** and **Continue** only; "the agent never touches a bot check,
  and nothing solves or skips one by itself".
- **No passwords:** "an agent never types a password. On a handed tab that needs a login, it asks the user to log in
  in that tab."
- **Page text is data:** "the chat sends no page data to agents, and the server drops it from watcher messages
  (Decision 9). A handed tab reaches the agent as a labelled line of page data (`page_line`)."
- **textContent only:** "agent names, conversation lines, hosts, card fields and `<option>` labels are set with
  `textContent`"; "the strip shows the host, never the page title". No `innerHTML`, `outerHTML` or
  `insertAdjacentHTML` in any watcher file.
- **Hand-over and take-back are clicks only:** "Start here, Hand over and Take back are trusted clicks, each with its
  own message"; "typing never hands a tab, and no code moves focus onto these buttons".
- **The Brain only proposes:** "the Brain and the voice have no path to `start_here`, `hand_here` or
  `take_back_here`"; the Brain's lines only point to the chat (Decision 17).
- **Downloads need the user's OK:** "In the user's Brave a download is a ⚠ step, and one that starts outside a
  confirmed step is cancelled (everyday-brave Decision 15). The chat adds no path around it."

**The watcher's powers:**
- "No new powers in the watcher but `sidePanel`": no `debugger`, no new host permission, no `externally_connectable`,
  no `web_accessible_resources`, no `incognito` other than "spanning", no `content_security_policy` key.
- No `chrome.debugger` anywhere in the watcher's folder, and never `nav.js` in it.
- "the chat registers no runtime message listener" (`runtime.onMessage`, `runtime.onConnect`, `onMessageExternal`,
  `onConnectExternal`).
- "no code path calls `chrome.sidePanel.open` for a window whose type isn't `normal`", and only `openChatFor` calls it.

**When Brave may be asked:**
- "`take_back_here` never connects"; "opening the chat, switching tabs, `hello`, `events` and `tab_owners` never
  connect".
- `start_here` and `hand_here` connect only through `_ready_for_hands`: "the same attempt as AI Home's Connect"
  (`InstanceLinks.connect(place, "connect")`); "a Deny is final until the next click: nothing retries by itself".
- `send` and `new_task` from the chat start an agent's turn, which may connect under the relay's `turn` rule, "as the
  same messages from AI Home do".

**Exact values:**
- `request`: "1 to 40 characters of `[A-Za-z0-9-]`", matched whole (`_TALK_ID.fullmatch`). "The server ignores a
  repeated `request` on the same socket", keeping "at most 200 per socket".
- `text`: "at most `TEXT_LIMIT` (20,000) characters".
- The tab descriptor `{id, window, url}`: "`id` and `window` are non-negative integers (a JSON `true` is not an
  integer), and `url` is a string that starts `http://` or `https://`, at most 2,000 characters".
- `MAX_CANDIDATES = 20`: "More than 20 candidates count as `ambiguous` at once, with no window lookups."
- Each hand button "is disabled while its request is open, until `hand_result` comes or 65 s pass".
- `tab_owners`: "at most every 100 ms after an owner or a recorded tab id changes".
- The manifest's description, exactly (132 characters): "Your agents' chat and the Brain's inbox, beside your tabs.
  It never presses Send; agents use your tabs only when you hand them over." Version "0.3.0".
- The shortcut: ⌘⇧Y on a Mac, Ctrl+Shift+Y elsewhere, "with `platforms.shortcut`" in the setup page and the terminal;
  "⌘⇧Y, or Ctrl+Shift+Y on Windows" in the README and AI Home.

**The words:**
- "the composer says **Tell** and **Start**, never **Send**": **Tell**, **Start**, **Start here · <host>**, **Start in
  its own tabs**, **Hand over to <n · name>**, **Stop**.
- The core promise: "It never presses Send for you. An agent works in one of your tabs only after you click Start
  here or Hand over."
- The first-run line: "This chat never presses Send for you. An agent works in one of your tabs only after you click
  Start here or Hand over, and it asks you before any ⚠ step like Send, Buy or Delete."
- The Allow line: "Only click Allow right after you started AI Browser, clicked Connect, gave an agent a task,
  switched to {name} in AI Browser's Settings, clicked Start here or Hand over in the chat beside your page, asked
  Claude Code to browse, or opened {name} again while an agent was working." The sentence after it stays the
  relay's.

**Nothing leaves the machine without a knowing choice:** "the chat talks only to 127.0.0.1"; "the tab's address goes
to the local server only on a hand click, and the server never logs it"; "the agents' place label in `panel_place`
... goes only to the chat on this computer, never to an agent or the Brain".

**Tests:**
- "Tests never reach the user's real browsers": the "Brave" is a throwaway Google Chrome with the watcher loaded, or
  `FakeBrave`; conftest's autouse fixtures stay.
- Run tests one file or one test at a time: `uv run pytest <path>::<test> -q -p no:randomly`. The whole suite runs
  only in the last task. Never connect to the user's own Brave or Chrome, and never touch a running `ai-browser app`.
- "On Windows: the unit tests run. The throwaway-browser tests skip there", with every test on the `watcher` fixture.

**House rules:** text files are read and written with `encoding="utf-8"`; no page text says "this Mac" or "⌘" unless
`tests/test_portable.py`'s `MAC_ONLY` lists it; the code's name wins over the spec's.

## Review Focus

The five failures most likely to hit a user that the spec implies but none of its tests cover. Each has a test in the
task that owns the code.
1. **A tab that changes while Brave's question is open.** The user clicks Start here, Brave asks, and meanwhile the
   user moves on in that tab (another Gmail thread). After Allow the server must match the address the click
   carried, find it gone, and answer "The page changed. Click again.", never hand the tab that now shows something
   else. Test: Task 7.
2. **An agent that closes while Brave asks.** Hand over to 1 · Fix the footer, Brave asks, and the agent is closed in
   the app window before Allow. The answer is "That agent has closed: nothing was handed", and the tab keeps no
   owner. Test: Task 7.
3. **Two windows, two chats, one click.** Both windows' chats are open in the same profile. Only the chat that
   clicked gets `created` and `hand_result`; both get the new `tab_owners`, so the other window's strip is right too.
   Test: Task 7.
4. **The picked agent closes while its conversation is shown.** **To:** falls back to **New agent** and the chat says
   "1 · Fix the footer has closed": never a stale agent in **To:**, never a blank chat. Test: Task 11.
5. **Shift+Enter in the text box.** It makes a new line and never tells, starts or hands anything. Test: Task 12.

```python
def test_tab_ids_are_known_both_ways_one_target_per_tab():
    from ai_browser.app.groups import GroupKeeper

    told = []
    keeper = GroupKeeper(lambda message: True)
    keeper.on_known = lambda: told.append(1)
    keeper.remember("T1", 41)
    keeper.remember("T2", 42)
    keeper.remember("T3", 41)  # tab 41 shows another target now: the latest wins
    assert keeper.target_of(41) == "T3" and keeper.target_of(42) == "T2"
    assert keeper.target_of(7) is None and keeper.target_of(True) is None
    assert keeper.tab_of("T1") is None and keeper.known() == {"T2": 42, "T3": 41}
    assert len(told) == 3  # the side chat's tab_owners follow every tab id learned
    keeper.known()["T9"] = 9  # a copy: changing it changes nothing
    assert keeper.target_of(9) is None
```

```python
"""The side chat's tests and wave C's places: which link is the agents' place, which place (and profile context) a
watcher copy's origin is in, and the chat's own socket. This file is the one place that knows how wave C's server
holds these (its plan's `attach_brave(link, place=)`, `Watchers.place_of`, `InstanceLinks.context_of` and
`Agent.where`); tests/test_sidechat_seams.py checks the outcome."""

from __future__ import annotations

import json

from websockets.asyncio.client import connect

from ai_browser.places import Place

WATCHER = "chrome-extension://watcher"  # the watcher copy's origin in the server tests (as in test_app_server)
CONTEXT = "C0"  # FakeBrave's default browser context (wave C's): the agents' profile in the server tests
PLACE = Place("brave", "/tmp/aib-tests/BraveSoftware/Brave-Browser", "Default")  # where agents work
WORK = Place("brave", "/tmp/aib-tests/BraveSoftware/Brave-Browser", "Profile 1")  # another profile, same browser
OTHER_BROWSER = Place("chrome", "/tmp/aib-tests/Google/Chrome", "Default")  # another browser
AGENT = {"kind": "agent", "id": "a1", "name": "Fix the footer", "color": "blue"}  # a1's owner, as the server makes it


def agents_place(server, link, place: Place = PLACE) -> None:
    """`link` (a FakeBrave, or the watcher fixture's real link) is the link of `place`, and `place` is the agents'
    place: the Settings choice, which new agents get."""
    server.attach_brave(link, place=place)  # wave C: a one-link InstanceLinks, `place` current, agents.place set


def chat_origin(server, origin: str, place: Place | None, context: str | None = CONTEXT) -> None:
    """The watcher copy at `origin` is in `place`, whose tabs are in browser context `context`. Wave C reads the place
    from the profile's files (its `Watchers.find_places` seam, read when a copy connects) and the context from the
    copy's worker; tests say both at once. `place=None` is a copy wave C couldn't place (its "unknown" or "shared"
    copy)."""
    watchers, links = server.watchers, server.links
    if "_rig_places" not in watchers.__dict__:
        watchers._rig_places, found = {}, watchers.place_of
        watchers.place_of = lambda asked: watchers._rig_places[asked] if asked in watchers._rig_places else found(asked)
    if "_rig_contexts" not in links.__dict__:
        links._rig_contexts, known = {}, links.context_of
        links.context_of = lambda asked: (links._rig_contexts[asked.key] if asked is not None
                                          and asked.key in links._rig_contexts else known(asked))
    watchers._rig_places[origin] = place
    if place is not None:
        links._rig_contexts[place.key] = context


def placed(agent, place: Place = PLACE):
    """An agent made by fake_brave.add_agent, as if started in `place` (wave C's Agent.where, and its public row)."""
    agent.where = place
    agent.place = {"browser": place.browser, "profile": place.profile, "label": f"{place.browser} · {place.profile}",
                   "color": None}
    return agent


async def chat_socket(server, url: str, origin: str = WATCHER):
    """The side chat on the app's socket: a watcher-origin socket that says hello as the chat (view "panel")."""
    ws = await connect(url.replace("http", "ws") + "/ws?token=" + server.token, origin=origin)
    await ws.send(json.dumps({"type": "hello", "view": "panel"}))
    return ws


def copy_groups(server, origin: str = WATCHER):
    """The GroupKeeper of the watcher copy connected at `origin` (wave C keeps one per copy)."""
    return next(conn.groups for conn in server.watchers.connections() if conn.origin == origin)
```

```python
"""Real input over CDP: the page sees these clicks and keys as the user's own (event.isTrusted), even in a background
tab. A script's element.click() is not trusted; these are."""

import json


async def _center(cdp, session, selector) -> tuple[float, float]:
    expression = (f"(() => {{ const node = document.querySelector({json.dumps(selector)}); "
                  "node.scrollIntoView({block: 'center'}); const box = node.getBoundingClientRect(); "
                  "return [box.left + box.width / 2, box.top + box.height / 2]; })()")
    result = await cdp.send("Runtime.evaluate", {"expression": expression, "returnByValue": True}, session_id=session)
    x, y = result["result"]["value"]
    return x, y


async def click(cdp, session, selector) -> None:
    x, y = await _center(cdp, session, selector)
    await cdp.send("Input.dispatchMouseEvent", {"type": "mouseMoved", "x": x, "y": y}, session_id=session)
    for kind in ("mousePressed", "mouseReleased"):
        await cdp.send("Input.dispatchMouseEvent", {"type": kind, "x": x, "y": y, "button": "left", "clickCount": 1},
                       session_id=session)


async def press_enter(cdp, session, shift=False) -> None:
    modifiers = 8 if shift else 0  # CDP's modifier bit for Shift
    await cdp.send("Input.dispatchKeyEvent", {"type": "keyDown", "key": "Enter", "code": "Enter",
                                              "windowsVirtualKeyCode": 13, "text": "\r", "modifiers": modifiers},
                   session_id=session)
    await cdp.send("Input.dispatchKeyEvent", {"type": "keyUp", "key": "Enter", "code": "Enter",
                                              "windowsVirtualKeyCode": 13, "modifiers": modifiers}, session_id=session)


async def type_text(cdp, session, text) -> None:
    """Types into the focused element, as the keyboard would."""
    await cdp.send("Input.insertText", {"text": text}, session_id=session)
```

```python
that show exactly that address in the chat's own profile, and keeps those in that window, asking the browser for each
target's window (Browser.getWindowForTarget: a browser-level call that never attaches to the tab). Exactly one left is
the tab. Two or more is "ambiguous" and none is "changed": the server refuses, and never guesses."""

from __future__ import annotations

from collections.abc import Awaitable, Callable, Iterable
from dataclasses import dataclass

MAX_CANDIDATES = 20  # more targets showing one address than this are "ambiguous" at once, with no window lookups
URL_LIMIT = 2000  # characters of the address a descriptor may carry


@dataclass(frozen=True)
class TabDesc:
    id: int  # Brave's tab id, as chrome.tabs numbers it
    window: int  # its window id, as chrome.windows numbers it
    url: str  # the address it shows: used for the match only, never logged


def _count(value) -> bool:
    """A non-negative integer; a JSON true or false is not one."""
    return isinstance(value, int) and not isinstance(value, bool) and value >= 0


def tab_desc(value) -> TabDesc | None:
    """The chat's tab descriptor, checked; None for anything else."""
    if not isinstance(value, dict):
        return None
    tab_id, window, url = value.get("id"), value.get("window"), value.get("url")
    if not (_count(tab_id) and _count(window) and isinstance(url, str)):
        return None
    if len(url) > URL_LIMIT or not url.startswith(("http://", "https://")):
        return None
    return TabDesc(tab_id, window, url)


async def resolve_tab(desc: TabDesc, candidates: Iterable[str],
                      window_of: Callable[[str], Awaitable[int | None]]) -> tuple[str | None, str]:
    """(target, "") for the one candidate in the descriptor's window, else (None, "ambiguous") or (None, "changed").
    The window is checked even for a single candidate: alone in another window, it means the user's tab no longer
    shows that address. A lookup that fails counts as another window."""
    targets = list(dict.fromkeys(candidates))
    if len(targets) > MAX_CANDIDATES:
        return None, "ambiguous"
    found = []
    for target in targets:
        try:
            window = await window_of(target)
        except Exception:  # a dropped connection, a closed tab: not this window
            window = None
        if _count(window) and window == desc.window:
            found.append(target)
    if len(found) == 1:
        return found[0], ""
    return None, "ambiguous" if found else "changed"
```

```python
        """Brave's tab id -> owner, for one chat (Decision 4): the agents', handed and Claude Code's tabs its browser
```

```python
    def _here_new(self, ws: WebSocket, request: str) -> bool:
        """False for a request id this socket sent before (a double click starts one agent); keeps the last HERE_SEEN
        ids per socket."""
        seen = self._here_seen.setdefault(ws, {})
        if request in seen:
            return False
        seen[request] = None
        while len(seen) > HERE_SEEN:
            del seen[next(iter(seen))]
        return True

    async def _here(self, ws: WebSocket, queue: asyncio.Queue, kind: str, message: dict) -> None:
        """Start here and Hand over, from the side chat: a trusted click on the user's own tab. The server finds the
        tab by its address and window, connects to the browser only now if it must, and checks again whose the tab
        is before it hands it over. Every way out answers hand_result."""
        request, desc = message["request"], tab_desc(message["tab"])

        def answer(reason: str = "", agent_id: str | None = None) -> None:
            reply = {"type": "hand_result", "request": request, "ok": not reason}
            if reason:
                reply["reason"] = reason
            elif agent_id is not None:
                reply["id"] = agent_id
            queue.put_nowait(reply)

        text = _text(message.get("text"))
        if kind == "start_here" and not text:
            answer("no_text")
            return
        where = self._panel_place(ws)
        if not where["hands"]:
            answer(where["why"])
            return
        place = self.links.current
        link = self.links.link_for(place)
        reason = await self._ready_for_hands(queue, request, link)
        if reason:
            answer(reason)
            return
        target, reason = await self._resolve_here(ws, link, place, desc)
        if target is None:
            answer(reason)
            return
        if kind == "start_here":
            info = self._handable(target)
            if info is None:
                answer("not_yours")
                return
            model = message.get("model") if message.get("model") in MODELS else self._model()
            agent = await self._start_in(target, info, text, model, request, queue, place=place)
            answer(agent_id=agent.id)
            return
        agent = self.agents.agents.get(str(message.get("id", "")))
        if agent is None:
            answer("closed")
            return
        if not self._same_place(agent, place):
            answer("other_place")
            return
        if await self._hand(agent.id, target):
            answer("closed" if agent.id not in self.agents.agents else "not_yours")
            return
        answer(agent_id=agent.id)

    async def _ready_for_hands(self, queue: asyncio.Queue, request: str, link) -> str:
        """"" once the agents' browser is connected, else why not (Decision 12). Not connected, it starts the same
        shared attempt as AI Home's Connect, right after the user's click, and says once that the browser is asking.
        A Deny ends it with "refused"; nothing tries again until the next click."""
        if link.state == "connected":
            return ""
        if link.state == "off":
            return "off"
        loop = asyncio.get_running_loop()
        attempt = asyncio.ensure_future(self.links.connect(self.links.current, "connect"))
        attempt.add_done_callback(lambda done: done.cancelled() or done.exception())  # its outcome is the state
        told, deadline = False, loop.time() + ALLOW_WAIT + 5
        while loop.time() < deadline:
            if link.state == "asking" and not told:
                told = True
                queue.put_nowait({"type": "hand_wait", "request": request, "why": "allow"})
            if attempt.done() and link.state != "asking":
                break
            await asyncio.sleep(0.05)
        return {"connected": "", "off": "off"}.get(link.state, "refused")

    async def _resolve_here(self, ws: WebSocket, link, place, desc) -> tuple[str | None, str]:
        """The chat's tab: the targets showing its exact address in the chat's own profile, then the one in its
        window, with one fresh read of the list before "changed". On success the chat's copy remembers which target
        that tab is, so the strip and Take back know it."""
        context = self.links.context_of(place)

        def candidates() -> list[str]:
            if context is None:
                return []
            return [target for target in link.targets_showing(desc.url) if link.context_of(target) == context]

        target, reason = await resolve_tab(desc, candidates(), link.window_of)
        if reason == "changed":
            await link.refresh()
            target, reason = await resolve_tab(desc, candidates(), link.window_of)
        if target is not None:
            copy = self._copy_of(ws)
            if copy is not None:
                copy.groups.remember(target, desc.id)
        return target, reason
```

The descriptor's address is used for the match only: nothing here logs it, and the agent gets the address from the
server's own list (`_start_in`, `_hand`).

Wave C's `_ungroup` finds a tab's copy and tab id with `watchers.tab_of(target)`, which asks each copy's GroupKeeper,
so the match recorded here is what lets Take back ungroup a tab handed from the chat (Task 8's test checks it).

```python
        """Take back, from the side chat: the target a copy in the chat's browser recorded for this tab id, when an
```

```js
// The chat beside your page, in Brave's side panel: one chat per window, following that window's active tab. Pick an
// agent in To: and tell it something, start a new one, hand it this tab or take the tab back (each its own click),
// and answer its cards. Its only line is the app's 127.0.0.1 socket. No page can reach it (it registers no runtime
// message listener), it never reads a tab's title, and everything from agents or pages is set as text.
import { agentLabel, createChat } from "./chat.js";
import { openBrain } from "./brainpage.js";
import { connect } from "./link.js";
import { defaultTo, modeFor, stripFor, toChoices, waitingLine } from "./sidechat.js";

const $ = (id) => document.getElementById(id);
const NEW_NOTE = "New agent: write what it should do.";
const agents = new Map(); // agent id -> its row (the server's copy for the watcher)
let windowId = null; // this chat's window, read once
let tab = null; // that window's active tab: {id, windowId, url}; its title is never read
let owners = {}; // tab_owners: Brave's tab id -> whose tab it is (an agent's, a handed one, Claude Code's)
let place = null; // panel_place: whether agents can use this tab, and if not, why
let to = "new"; // the agent picked in To:, or "new"
let drawn = null; // whose conversation is drawn
let connected = false;
let defaultModel = "sonnet";
let storedModel = false; // the user picked a model here before: it wins over the app's
const chat = createChat($("messages"));
const link = connect({ view: "panel", onMessage: handle, onState: setStatus });

function hint(text) {
  $("hint").textContent = text;
}

function ownerOfTab() {
  return tab ? owners[String(tab.id)] || null : null;
}

function currentMode() {
  return modeFor({ to, strip: stripFor({ tab, owner: ownerOfTab(), place }), place, connected });
}

function pick(id) {
  to = id;
  if (drawn === to) return;
  drawn = to;
  if (to === "new") {
    chat.reset(NEW_NOTE);
  } else {
    chat.reset("Loading…");
    link.send({ type: "events", id: to });
  }
}

function closed(id) {
  const agent = agents.get(id);
  agents.delete(id);
  if (to !== id) return;
  to = "new";
  drawn = "new";
  chat.reset(`${agent ? agentLabel(agent) : "That agent"} has closed`);
}

function renderStrip(strip) {
  $("strip-text").textContent = strip.text;
  $("strip-note").textContent = strip.note;
  $("strip-note").hidden = !strip.note;
}

function renderTo() {
  const select = $("to");
  const choices = toChoices(agents);
  const key = JSON.stringify(choices);
  if (select.dataset.key !== key) {
    select.replaceChildren(...choices.map(({ value, label }) => {
      const option = document.createElement("option");
      option.value = value;
      option.textContent = label;
      return option;
    }));
    select.dataset.key = key;
  }
  select.value = to;
}

function renderComposer(strip, mode) {
  const agent = to === "new" ? null : agents.get(to) || null;
  $("tell").hidden = mode !== "tell";
  $("input").disabled = mode === "off";
  $("input").placeholder = agent ? `Tell ${agentLabel(agent)}` : "What should a new agent do?";
  $("stop").hidden = !(agent && (agent.state === "working" || agent.state === "waiting" || agent.check));
}

function renderWaiting() {
  const line = waitingLine(agents, to);
  $("waiting").hidden = !line;
  $("waiting-text").textContent = line ? line.text : "";
}

function renderModel() {
  if (document.activeElement === $("model")) return;
  const agent = to === "new" ? null : agents.get(to);
  $("model").value = agent?.model || defaultModel;
}

function render() {
  const strip = stripFor({ tab, owner: ownerOfTab(), place });
  const mode = modeFor({ to, strip, place, connected });
  renderStrip(strip);
  renderTo();
  renderComposer(strip, mode);
  renderWaiting();
  renderModel();
  $("offline").hidden = connected;
}

function tell() {
  const text = $("input").value.trim();
  if (to === "new" || !text) return;
  if (!link.send({ type: "send", id: to, text })) {
    hint("Not connected: is ai-browser app running?");
    return;
  }
  $("input").value = "";
  hint("");
  render();
}

function onEnter() {
  if (currentMode() === "tell") tell();
}

async function readTab() {
  if (windowId === null) return;
  let active = null;
  try {
    [active] = await chrome.tabs.query({ active: true, windowId });
  } catch {
    active = null;
  }
  const next = active ? { id: active.id, windowId: active.windowId, url: active.url || active.pendingUrl || "" }
    : null;
  const changed = (next?.id ?? null) !== (tab?.id ?? null);
  tab = next;
  if (changed) pick(defaultTo({ current: to, owner: ownerOfTab(), agents, tabChanged: true }));
  render();
}

function handle(message) {
  switch (message.type) {
    case "snapshot":
      agents.clear();
      for (const agent of message.agents || []) agents.set(agent.id, agent);
      drawn = null; // a new connection: draw the conversation again
      pick(defaultTo({ current: to, owner: ownerOfTab(), agents, tabChanged: false }));
      break;
    case "agent":
      agents.set(message.agent.id, message.agent);
      break;
    case "agent_closed":
      closed(message.id);
      break;
    case "agent_event":
      if (message.id === drawn) chat.append(message.event);
      break;
    case "agent_events":
      if (message.id === drawn) {
        chat.reset();
        for (const event of message.events || []) chat.append(event);
      }
      break;
    case "panel_place":
      place = message;
      if (!storedModel && message.model) defaultModel = message.model;
      break;
    case "tab_owners": {
      const before = ownerOfTab()?.id;
      owners = message.owners || {};
      const owner = ownerOfTab();
      if (owner && owner.id !== before) pick(defaultTo({ current: to, owner, agents, tabChanged: true }));
      break;
    }
    case "error":
      if (message.text) hint(message.text);
      break;
    default:
      return;
  }
  render();
}

function setStatus(state) {
  connected = state === "connected";
  $("status").dataset.state = state;
  $("status").title = connected ? "Connected to ai-browser app" : state === "connecting" ? "Connecting…"
    : "AI Browser isn't running: start ai-browser app";
  render();
}

$("input").addEventListener("keydown", (event) => {
  if (event.key !== "Enter" || event.shiftKey || event.isComposing) return; // Shift+Enter: a new line
  event.preventDefault();
  if (event.isTrusted) onEnter();
});
$("input").addEventListener("input", () => render());
for (const button of document.querySelectorAll("button")) { // a click never takes the focus from the text box
  button.addEventListener("mousedown", (event) => event.preventDefault());
}
$("tell").addEventListener("click", (event) => { if (event.isTrusted) tell(); });
$("stop").addEventListener("click", () => { if (to !== "new") link.send({ type: "stop", id: to }); });
$("to").addEventListener("change", () => {
  pick($("to").value);
  hint("");
  render();
});
$("model").addEventListener("change", () => {
  const model = $("model").value;
  if (to !== "new") {
    link.send({ type: "model", id: to, model });
  } else {
    defaultModel = model;
    storedModel = true;
    chrome.storage.local.set({ model }).catch(() => {}); // a convenience only
  }
});
$("inbox").addEventListener("click", () => { openBrain().catch(() => {}); });
$("waiting-show").addEventListener("click", () => {
  const line = waitingLine(agents, to);
  if (line) pick(line.id);
  render();
});
$("got-it").addEventListener("click", () => {
  $("first-run").hidden = true;
  chrome.storage.local.set({ promise2Seen: true }).catch(() => {});
});
chrome.tabs.onActivated.addListener((info) => { if (info.windowId === windowId) readTab(); });
chrome.tabs.onUpdated.addListener((id, change) => {
  if (tab && id === tab.id && (change.url !== undefined || change.status !== undefined)) readTab();
});
chrome.tabs.onAttached.addListener((id, info) => { if (info.newWindowId === windowId) readTab(); });
chrome.tabs.onDetached.addListener((id, info) => { if (info.oldWindowId === windowId) readTab(); });
chrome.tabs.onRemoved.addListener((id, info) => { if (info.windowId === windowId) readTab(); });

(async () => {
  try {
    const stored = await chrome.storage.local.get(["model", "promise2Seen"]);
    if (stored.model) {
      defaultModel = stored.model;
      storedModel = true;
    }
    $("first-run").hidden = stored.promise2Seen === true;
  } catch {
    $("first-run").hidden = false; // the flag is only a convenience: unread, the line shows
  }
  document.body.dataset.promise = "read";
  try {
    windowId = (await chrome.windows.getCurrent()).id; // the window this chat sits in, once
  } catch {
    windowId = null;
  }
  await readTab();
})();
```

```js
function busy(button) {
  return [...pending.values()].some((entry) => entry.button === button);
}

function ask(button, message) {
  requests += 1;
  const request = `c${Date.now().toString(36)}-${requests}`;
  if (!link.send({ ...message, request })) {
    hint("Not connected: is ai-browser app running?");
    return;
  }
  const timer = setTimeout(() => { pending.delete(request); render(); }, HAND_WAIT);
  pending.set(request, { button, kind: message.type, agent: message.id, timer });
  hint("");
  render();
}

function finish(request) {
  const entry = pending.get(request);
  if (entry) {
    clearTimeout(entry.timer);
    pending.delete(request);
  }
  return entry;
}

function descriptor() { // what the server needs to find the tab, never its title; null for a tab it can't take
  if (!tab || !isWebPage(tab.url) || tab.url.length > 2000) return null;
  return { id: tab.id, window: tab.windowId, url: tab.url };
}

function startOwn(button) {
  const text = $("input").value.trim();
  if (!text || busy(button)) return;
  ask(button, { type: "new_task", text, model: $("model").value });
}

  if (!event.isTrusted) return; // only the user's own click hands a tab over
  const text = $("input").value.trim();
  if (!text) {

    return;
  }
  const described = descriptor();
  if (!described) {
    hint(reasonText("bad_tab"));
    return;
  }
  if (busy("start-here")) return;
  ask("start-here", { type: "start_here", text, model: $("model").value, tab: described });
}
```

```js
// The side panel's set-up in the worker, and the one place the code opens the chat. The browser itself opens the
// chat from the watcher's icon or its shortcut (openPanelOnActionClick), in that window. A tab whose window isn't a
// normal one (a site's sign-in popup) gets its panel switched off: Brave crashes when an extension opens a side panel
// for a popup window's tab (brave/brave-browser#59256). The `api` parameter lets tests pass a fake.

export function setUpSidePanel(api = chrome) {
  api.sidePanel.setPanelBehavior({ openPanelOnActionClick: true }).catch(() => {});
  api.tabs.onCreated.addListener((tab) => { guardTab(tab, api).catch(() => {}); });
  api.tabs.onAttached.addListener((tabId) => {
    api.tabs.get(tabId).then((tab) => guardTab(tab, api)).catch(() => {});
  });
  api.windows.getAll({ populate: true, windowTypes: ["normal", "popup", "panel", "app", "devtools"] })
    .then((windows) => Promise.all(windows.flatMap((win) => (win.tabs || []).map((tab) => guardTab(tab, api)))))
    .catch(() => {});
}

// A tab in a window that isn't normal gets no chat. A tab moved from a popup into a normal window keeps it switched
// off: switching it on again would make it a per-tab panel. That rare tab simply has no chat.
export async function guardTab(tab, api = chrome) {
  if (!tab || typeof tab.id !== "number" || tab.id < 0) return false;
  const win = await api.windows.get(tab.windowId).catch(() => null);
  if (!win || win.type === "normal") return false;
  await api.sidePanel.setOptions({ tabId: tab.id, enabled: false });
  return true;
}

export async function windowOf(tabId, api = chrome) {
  const tab = await api.tabs.get(tabId).catch(() => null);
  if (!tab) return null;
  const win = await api.windows.get(tab.windowId).catch(() => null);
  return win ? { id: win.id, type: win.type } : null;
}

// The Brain page's Chat button: synchronous, with nothing waited on before open(), so the click's gesture holds. It
// opens nothing unless the window is a normal one.
export function openChatFor(win, api = chrome) {
  if (!win || win.type !== "normal" || typeof win.id !== "number") return false;
  api.sidePanel.open({ windowId: win.id }).catch(() => {});
  return true;
}
```
