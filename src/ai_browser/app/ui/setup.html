Set up AI Browser

Two one-time steps, both in Brave, your everyday browser. AI Browser's own window needs nothing.

The Brain's watcher, in Brave

Once: the Brain watches the sites you pick (Gmail, Slack, Asana…) in Brave, through a small extension. It reads new messages and never sends anything.

  1. In Brave, open brave://extensions and turn on Developer mode.
  2. Drag the watcher folder onto that page.

    Or click Load unpacked, {{GOTO}}, then Select. The folder:

    {{WATCHER}}
  3. Click the watcher's icon to open the Brain, and switch on the sites to watch.
  4. Type ai and a space in Brave's address bar to start a task from there.

Waiting for the watcher…

Let agents use your Brave

Agents browse in Brave, your everyday browser, where you are already signed in: in background tabs of their own, grouped and named after their task. Brave's own remote-debugging switch lets them in. You turn it on yourself, and Brave asks before it lets a connection in.

  1. In Brave, open brave://inspect/#remote-debugging.
  2. Tick Allow remote debugging for this browser instance.
  3. When Brave asks Allow remote debugging?, click Allow. AI Browser holds one connection for all its agents and Claude Code sessions, so Brave asks once each time AI Browser starts, and again after Brave restarts.

While this switch is on, any program on {{THIS_COMPUTER}} can reach your Brave, not only AI Browser. That includes the sites you are signed in to.

While AI Browser is connected, a program that can read AI Browser's files can also use your Brave through it without a new question. AI Home lists everything connected, with Disconnect.

Turn it off when agents aren't working: untick the same box.

Only click Allow right after you started AI Browser, clicked Connect, gave an agent a task, asked Claude Code to browse, or opened Brave again while an agent was working. If Brave asks at any other time, it isn't AI Browser: click Deny, unless you just started another browser tool yourself.

While AI Browser is connected, Brave shows a bar saying it is being controlled by automated test software. That is Brave telling you the truth; AI Browser never hides or closes it. If you close it yourself, it comes back only when AI Browser or Brave restarts.
